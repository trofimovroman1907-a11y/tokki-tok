# Темы MargyT (.mttheme)

Тема это обычный текстовый файл с расширением `.mttheme`. Внутри JSON с цветами
и парой переключателей: акцент, цвета интерфейса для светлой и тёмной темы
TikTok, лайки, AMOLED и стиль интерфейса. Кода в теме нет, она ничего не
запускает, поэтому ставить чужие темы безопасно.

## Как поставить

- Открыть файл `.mttheme` из файлового менеджера или Telegram и выбрать
  «Тема MargyT». Мод покажет название, автора и описание и спросит, применять ли.
- Или в настройках MargyT: Оформление → Тема → «Установить тему .mttheme».

Тема применяется сразу, перезапуск не нужен. Название последней темы видно под
кнопкой установки.

## Как сделать свою

Проще всего не писать файл с нуля:

1. Настроить всё в MargyT как нравится: акцент, цвета в «Цветах интерфейса»,
   движок тем, AMOLED, стиль.
2. Нажать «Сохранить тему в файл», ввести название и выбрать, куда сохранить.
3. Открыть файл в любом редакторе текста, поправить что нужно, дописать
   `author` и `description`.

Готовый пример лежит в [examples/mint-night.mttheme](../examples/mint-night.mttheme).

## Файл целиком

```json
{
  "mttheme": 1,
  "name": "Мятная ночь",
  "author": "narezany",
  "description": "Тёмная тема с мятным акцентом.",
  "accent": "#5BE7B9",
  "design": "md3",
  "amoled": false,
  "engine": {
    "on": true,
    "wallpaper": false,
    "strength": 100,
    "dark":  { "background": "#0E1714", "text": "#E6FFF5" },
    "light": { "background": "#F1FFF9", "text": "#0B2019" }
  },
  "dark":  { "background": "#0E1714", "text": "#E6FFF5", "control": "#5BE7B9" },
  "light": { "background": "#F1FFF9", "text": "#0B2019", "control": "#14986E" },
  "likes": { "feed": "#FF5C8A", "comment": "#FF5C8A" }
}
```

Обязательны только `mttheme` и `name`. Всё остальное можно не писать: чего нет в
теме, то мод не трогает.

## Поля

| Поле | Что это |
|---|---|
| `mttheme` | Версия формата. Сейчас `1`. Обязательно. |
| `name` | Название, до 60 знаков. Обязательно. |
| `author` | Автор, до 60 знаков. |
| `description` | Пара слов о теме, до 400 знаков. |
| `accent` | Цвет акцента: кнопки, переключатели, всё, что в TikTok розовое. |
| `design` | Стиль интерфейса: `md3`, `glass` (жидкое стекло) или `fluent`. |
| `amoled` | `true` даёт чисто чёрный фон в тёмной теме. |
| `engine` | Движок тем, см. ниже. |
| `dark` | Цвета интерфейса для тёмной темы TikTok, см. роли. |
| `light` | То же для светлой темы TikTok. |
| `likes` | `feed` лайки в ленте, `comment` лайки комментариев. |

### engine

Движок тем перекрашивает весь TikTok по фону и тексту.

| Поле | Что это |
|---|---|
| `on` | Включён ли движок. Если `engine` есть, по умолчанию `true`. |
| `wallpaper` | `true` берёт цвета с обоев телефона (Android 12 и новее), тогда `background` и `text` не нужны. |
| `strength` | Насколько фон окрашен цветом, от `0` (почти чёрный или белый) до `100` (цвет как есть). |
| `dark` / `light` | `background` и `text` для тёмной и светлой темы. |

### Роли цветов

Эти ключи пишутся внутри `dark` и `light`. Можно указать только нужные.

| Роль | Что красит |
|---|---|
| `background` | Основной фон |
| `secondary_background` | Дополнительный фон |
| `surface` | Панели и карточки |
| `text` | Основной текст |
| `secondary_text` | Вторичный текст |
| `divider` | Разделители |
| `selected_tab` | Выбранная вкладка |
| `nav_icon` | Значки навигации |
| `control` | Активные элементы |
| `switch` | Включённые переключатели |
| `progress` | Ползунки и прогресс |
| `profile` | Акцент профиля |
| `nickname` | Цвет ника |

Акцент задаётся полем `accent` на верхнем уровне, а не ролью внутри `dark` и `light`.

## Цвета

Цвет пишется как `#RRGGBB`, например `#5BE7B9`. Можно и `#AARRGGBB`, но
прозрачность не учитывается: цвета темы всегда сплошные.

## Что происходит при установке

- Цвета ролей прошлой темы сначала стираются, чтобы две темы подряд не смешались.
- Если в файле есть ошибка (не тот формат цвета, неизвестный стиль, нет названия),
  тема не ставится совсем, и мод пишет, что не так. Половину темы он не ставит.
- Незнакомые поля пропускаются. Так тема, сделанная для будущей версии с новыми
  полями, всё равно встанет, если её `mttheme` не больше, чем знает мод.
- Файл больше 64 КБ не принимается.

Какой набор цветов работает, `dark` или `light`, решает сам TikTok по своей
теме. Поэтому хорошая тема описывает оба.
